# Getting help with SightPress

SightPress is a CMS for everyone, designed with blind and low-vision creators and audiences in mind.

## Read the documentation

The [SightPress documentation](https://docs.sightpress.org/) explains how to install SightPress, create a website
and use every feature, in plain English. Start with
[Getting started](https://docs.sightpress.org/latest/getting-started/).

## Ask a question

Ask in [GitHub Discussions](https://github.com/sightpress/core/discussions), in the *Q&A* category. Someone from the
community or a maintainer will answer there, so the answer helps the next person too.

If you can't use GitHub, or would rather not create an account, email <contribute@sightpress.org>.

## Report a problem

- Something doesn't work: [open an issue](https://github.com/sightpress/core/issues/new/choose) and choose
  **Report a problem**.
- Something stops you because of how SightPress works with your assistive technology, keyboard, zoom or colour
  settings: choose **Report an accessibility barrier**. Accessibility barriers are always treated as bugs.
- A security problem: never in public. See the [security policy](SECURITY.md).

## What we can and can't do

SightPress is looked after by volunteers. We answer as soon as we can, usually within 5 working days. We can't log in
to your server or website for you, and we can't give legal advice, for example about privacy law.
