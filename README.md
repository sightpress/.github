# SightPress community health files

This repository holds the default community files of every SightPress repository: the
[Code of Conduct](CODE_OF_CONDUCT.md), the [contributing guide](CONTRIBUTING.md), [getting help](SUPPORT.md), the
[security policy](SECURITY.md) and the issue forms. A repository that has its own copy of a file uses that instead.

SightPress is a CMS for everyone, designed with blind and low-vision creators and audiences in mind.
